## Відповіді на контрольні питання

**1. Що таке чисельні методи?**

Чисельні методи — це алгоритмічні способи наближеного розв'язування математичних задач із використанням обчислювальної техніки. Вони оперують наближеними значеннями, враховують похибку округлення, реалізуються програмно й орієнтовані на ефективність обчислень.

**2. Які типи задач розв'язуються чисельними методами?**

- розв'язування систем лінійних рівнянь;
- інтерполяція та апроксимація;
- чисельне диференціювання та інтегрування;
- оптимізація;
- розв'язування диференціальних рівнянь.

**3. Які переваги NumPy?**

- ефективна робота з багатовимірними масивами (`ndarray`);
- висока швидкість обчислень, бо операції реалізовані мовою C;
- векторизовані операції без явних циклів Python;
- вбудовані засоби лінійної алгебри (`numpy.linalg`): розв'язування систем, обернені матриці, визначники, власні значення;
- основа для інших наукових бібліотек (SciPy, Matplotlib, pandas).

**4. Для чого використовується Git?**

Git — розподілена система контролю версій. Вона дозволяє зберігати історію змін, працювати з різними версіями коду, повертатися до попередніх станів, а також організувати індивідуальну та командну роботу (зокрема через віддалені репозиторії на GitHub).

**5. Чому лабораторні необхідно зберігати у системі контролю версій?**

- зберігається повна історія виконання кожної роботи, і можна відновити будь-яку попередню версію;
- код не втрачається при збої комп'ютера, бо існує копія на GitHub;
- усі лабораторні зібрані в одному репозиторії з єдиною структурою;
- викладачу зручно перевіряти роботи за посиланням на репозиторій;
- формується навичка роботи з Git, необхідна в реальній розробці.
