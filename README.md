# numerical_methods_2026

Лабораторні роботи з дисципліни «Методи та технології обчислень».

Автор: Михайло Дораж

## Структура

| Папка  | Робота                                                              |
|--------|---------------------------------------------------------------------|
| `lab0` | Вступна: організація робочого середовища, основи Python і Git       |
| `lab1` | Інтерполяція кубічними сплайнами (профіль висоти Заросляк → Говерла) |

Кожна лабораторна робота знаходиться в окремій папці `labN/` і містить:
- `main.py` — програмний код;
- `report.md` або `report.pdf` — звіт.

## Середовище

- Python 3.13
- PyCharm Community
- NumPy, Matplotlib (`pip install numpy matplotlib`)
- Git
